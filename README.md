# Task 4: Build a REST API with Flask

## Project Description
Created a REST API using Python and Flask to manage user data.

## Tools Used
- Python
- Flask
- Postman

## API Methods
1. **GET** – Retrieve user details.
2. **POST** – Add a new user.
3. **PUT** – Update existing user details.
4. **DELETE** – Delete a user.

## Testing
Tested all four API methods using Postman.

## Project Files
- `app.py` – Flask application code.
- Screenshots – API testing results for GET, POST, PUT, and DELETE.
